# Preferencias al trabajar con Claude

- **Quiere respuestas rápidas y directas** en pedidos sencillos: sin preámbulos largos, sin acumular advertencias o alternativas cuando solo pide una acción o respuesta puntual. Dijo explícitamente que Claude "dura mucho haciendo sencilleces". Las explicaciones largas se reservan para acciones genuinamente riesgosas o complejas.

Fuente: memoria persistente (`feedback_be_concise`, `feedback_proactive_skills`) + este mismo chat.
